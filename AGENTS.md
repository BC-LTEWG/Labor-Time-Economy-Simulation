# Instructions for AI agents

Labor-Time-Economy-Simulation: an agent-based simulation of an economy that measures value in labor time (C++ engine, Python Overseer UI).

## Before you write anything

Read [docs/cpp-style-guide.md](docs/cpp-style-guide.md) and [docs/git-workflow.md](docs/git-workflow.md) and follow them for every name, design choice, document, commit and pull request.

- Check names against the style guide; never copy them from existing code.
- Cite rule ids (`N21`, `D3`, `G1`) in reviews when a change is about a rule.
- Never invent a source, section number or reference (D9).
- When asked to change one section of a document, change only that section.
